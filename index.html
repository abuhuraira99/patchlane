The caller picks which object to act on

Unless the server checks that this loan belongs to the signed-in borrower, any borrower can read someone else's. The id is a number, so neighbouring ids are easy to guess.

ExpressFastAPIDjangoLaravelSpring

The pattern in FastAPI (Python)

@router.get("/orders/{order_id}", response_model=OrderOut)
def get_order(order_id: int, user: User = Depends(current_user),
              db: Session = Depends(get_db)):
    # Scope the query to the caller; never accept a user id from the client.
    order = db.scalar(select(Order).where(
        Order.id == order_id, Order.owner_id == user.id))
    if order is None:
        # Same 404 for "missing" and "not yours", so ids cannot be probed.
        raise HTTPException(status_code=404, detail="not_found")
    return order

Written for an example route: put in the route, parameter and model of GET /v1/loans/{loanId}.

Prove it is fixed

Scenario: A user cannot reach another user's object
  Given user "alice" owns a record with loanId "A-1"
  And user "bob" is signed in
  When bob sends GET /v1/loans/{loanId} with loanId "A-1"
  Then the response status is 404

What teams ask before they paste a spec in.

Ask a question on GitHub

Does my spec leave the browser?

No. The checks run in the tab, and the site is static files with no server to receive anything.

What can a spec not tell you?

Whether the server really enforces ownership, limits and scopes. Each finding says what to confirm, and the Gherkin tests prove it.

Which API files does Patchlane read?

OpenAPI 3.x or Swagger 2.0, raw HTTP responses, JWTs, and MCP, OpenAI or Anthropic tool lists.

Does it send requests to my API?

Never. It reads what you paste, and the CLI runs offline in CI.

Is the Patchlane source code open?

Yes, MIT licensed on GitHub: the engine, its tests, the CLI and the Action.
